## 🚀 Projetos em destaque

### 🤖 JARBIS — Assistente de voz com IA
Assistente virtual para desktop, controlado por voz, inspirado no Jarvis.
- Reconhecimento de voz local com **Whisper** e IA local com **Ollama**
- Executa comandos no computador: abre aplicativos, pastas e sites
- Cria e executa projetos (como jogos em HTML) a partir de pedidos falados
- Controle de autorização para ações sensíveis e medição de desempenho por comando
- **Tecnologias:** Electron, Node.js, Python, Whisper, Ollama

### 🛒 Sistema de Vendas
Sistema web completo de gestão de vendas, do cadastro de produtos à finalização de pedidos.
- Cadastro e gerenciamento de produtos
- Carrinho de compras e finalização de pedidos
- **Tecnologias:** PHP, HTML, JavaScript

### 📅 Sistema de Agendamento Online
Plataforma web para agendamento de serviços, com interface amigável e responsiva.
- Gerenciamento de horários disponíveis
- Interface adaptada para celular e computador
- **Tecnologias:** PHP, HTML, JavaScript
